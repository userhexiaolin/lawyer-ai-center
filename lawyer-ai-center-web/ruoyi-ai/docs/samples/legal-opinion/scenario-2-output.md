# 法律意见书

## 1. 案件事实时间线

1. **2026年3月1日**：王某进入某公司从事设计工作，月报酬约定为8000元（依据：王某陈述）。
2. **2026年3月1日至2026年5月20日期间**：王某持续工作，存在部分考勤截图、工作群记录及三个月银行流水（依据：现有材料）。工资发放主体与用工主体一致性尚不明确（依据：现有材料）。
3. **2026年5月20日**：公司通过微信通知王某不必再来（依据：王某陈述/公司说法）。
4. **当前状态**：双方未签订书面劳动合同；公司主张王某为项目外包人员；离职补偿未协商（依据：双方说法及现有材料）。



## 2. 争议焦点

1. **劳动关系还是劳务/外包关系**：王某与公司之间是受公司管理的劳动关系，还是基于项目合作的劳务/外包关系？核心在于公司是否对王某进行考勤、指挥监督及发放工资。
2. **工资发放主体与用工主体是否一致**：银行流水显示的发薪方是否为“某公司”？若不一致，实际用工主体是谁？
3. **程序选择**：鉴于劳动关系认定存在争议，是直接申请劳动仲裁，还是先通过诉讼确认劳动关系，或是以劳务合同纠纷起诉？



## 3. 法律分析

1. **关于劳动关系认定**：
   - **依据**：根据原劳动和社会保障部《关于确立劳动关系有关事项的通知》（劳社部发〔2005〕12号），确立劳动关系需同时具备：(1)用人单位和劳动者符合法律主体资格；(2)用人单位依法制定的各项劳动规章制度适用于劳动者，劳动者受用人单位的劳动管理，从事用人单位安排的有报酬的劳动；(3)劳动者提供的劳动是用人单位业务的组成部分。
   - **事实匹配**：王某有考勤截图、工作群记录，显示其受公司管理（考勤、群聊指令），且从事设计工作（公司业务组成部分）。公司主张“外包”，但需举证证明存在合法的外包协议及王某与第三方存在劳动关系或劳务关系。若公司无法证明外包关系，仅凭微信通知解除，倾向于认定存在事实劳动关系。
   - **结论**：王某主张劳动关系的可能性较大，但需进一步核实工资发放主体。若发薪方非该公司，需厘清是代发、劳务派遣还是外包。

2. **关于报酬核对**：
   - **依据**：《劳动合同法》规定，用人单位应当按照劳动合同约定和国家规定，向劳动者及时足额支付劳动报酬。
   - **事实匹配**：王某主张月薪8000元，有三个月银行流水佐证。若流水金额与主张一致，且发薪主体明确，则报酬事实清楚。
   - **结论**：若认定为劳动关系，公司需补足未签劳动合同的双倍工资差额（最多11个月）及支付解除劳动关系的经济补偿金（N）。若认定为劳务关系，则按约定或实际履行支付报酬，无双倍工资及经济补偿。

3. **关于程序选择**：
   - **依据**：劳动争议需先仲裁后诉讼（《劳动争议调解仲裁法》第五条）；劳务纠纷可直接诉讼。
   - **事实匹配**：鉴于劳动关系认定存在争议（公司抗辩外包），直接申请劳动仲裁可能被驳回或要求先确认劳动关系。
   - **结论**：建议先以“确认劳动关系”为诉求申请劳动仲裁。若仲裁委不予受理或裁决不支持，再向法院起诉确认劳动关系，进而主张相关权益。



## 4. 风险与可行性

1. **证据风险**：微信通知“不必再来”是否构成违法解除？若公司能证明王某严重违反规章制度或不符合录用条件，可能无需支付赔偿金。目前缺乏公司规章制度公示及王某违纪证据。
2. **主体混同风险**：若工资由第三方公司发放，且公司主张外包，可能涉及实际用工主体认定困难，导致仲裁/诉讼对象错误，增加程序成本。
3. **时效风险**：劳动争议申请仲裁的时效期间为一年，从当事人知道或者应当知道其权利被侵害之日起计算。王某需确认离职时间（2026年5月20日）是否在时效内。
4. **外包抗辩风险**：若公司能提供与王某或第三方签订的合法外包/劳务协议，且王某工作具有独立性、非公司核心业务，可能被认定为劳务关系，从而丧失双倍工资及经济补偿金。



## 5. 策略建议

1. **证据补强**：
   - 收集并公证微信聊天记录（特别是考勤指令、工作安排、解除通知）。
   - 调取完整银行流水，明确发薪主体。
   - 收集工作成果、工牌、邮件签名等证明受公司管理的证据。
   - 尝试与公司沟通录音，诱导公司承认“员工”身份或“外包”具体安排。
2. **程序步骤**：
   - 第一步：向公司注册地或劳动合同履行地劳动人事争议仲裁委员会申请仲裁，诉求包括：确认劳动关系、支付未签劳动合同双倍工资差额、支付解除劳动关系经济补偿金。
   - 第二步：若仲裁委以“不属于劳动争议”为由不予受理，凭不予受理通知书向法院起诉确认劳动关系。
3. **对方视角及应对**：
   - **对方抗辩**：公司可能主张王某为外包人员，与公司无劳动关系，双方系平等民事主体间的劳务/承揽关系。
   - **应对**：强调王某受公司考勤管理、遵守公司规章制度、工作内容为公司业务组成部分，符合劳动关系从属性特征。要求公司举证外包协议的合法性及王某与第三方的关系。
