# 智能助手

#### 介绍
智能助手是一个基于 uni-app 开发的多端对话应用，通过 AI 为用户提供日常问答与创作辅助。支持多平台部署（微信小程序、H5、App 等）。

#### 软件架构
- 前端：uni-app + Vue2 + uView UI
- 后端：Spring Boot + WebSocket / SSE
- AI模型：通用大语言模型

#### 功能特性
1. **智能对话**：与 AI 进行多轮自然语言对话
2. **专业助理**：基于后端智能体列表选择对应助理对话
3. **创作大师**：内容创作辅助
4. **多端支持**：H5 / 小程序 / App 一套代码

#### 安装教程
1. 克隆项目到本地
2. 安装依赖：在项目根目录执行 `npm install`
3. 使用 HBuilderX 打开项目（菜单「文件」→「打开目录」，选择项目根目录）
4. 配置后端服务地址（common/config.js）
5. 在 HBuilderX 中选择运行目标平台（「运行」→「运行到浏览器/小程序/手机或模拟器」）

#### HBuilderX 使用教程
1. 前往 [HBuilderX 官网](https://www.dcloud.io/hbuilderx.html) 下载并安装（建议选「App 开发版」）
2. 安装依赖后，用 HBuilderX 打开项目根目录
3. 顶部菜单「运行」选择目标平台：
   - **H5**：运行到浏览器
   - **微信小程序**：运行到微信开发者工具（需提前安装并配置 AppID）
   - **App**：运行到手机或模拟器
4. 调试期间可使用 HBuilderX 内置控制台查看日志

#### 使用说明
1. 启动后进入首页
2. 在「专业助理」选择对应智能体进入对话
3. 在输入框输入内容发送
